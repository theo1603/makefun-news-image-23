exam-cheating row, and India's record 720 in Wellington — plus Myanmar on
ASEAN, the Lisbon march, the Java factory fire search, and the ICE detention
in Seattle in the also-today strip. Every headline is set from the day's
reporting; the image is drawn programmatically, so no text can garble.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024x1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Deterministic, no network, standard library
only.
